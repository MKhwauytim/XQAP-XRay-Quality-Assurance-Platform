# Edit Log — 2026-09-01

## v131.1 — 2026-09-01 — Change (user-management): merge activity and actions log pages into one

**Why:** "متابعة الأنشطة" (login/session activity) and "سجل الإجراءات" (the workspace action log) were two separate sidebar sub-tabs under إدارة المستخدمين, each its own permission-matrix row, for two views an admin almost always wants side by side. The owner asked to merge them into one page.

**What changed:** Collapsed the two sub-tabs into one, `user-management/activity`, relabeled "النشاط والإجراءات". Inside it, a small inner toggle (reusing the existing `um-feat-nav`/`um-feat-tab` styling from the feature-permissions group switcher) switches between the unchanged `ActivitySection` and `ActionsSection` components — no data-layer changes, no new CSS. The heavier action-log read still only fires the first time a user flips to that view, matching the old per-sub-tab lazy-load behavior (now keyed off the inner toggle state instead of the removed `"actions"` route). `ActivitySection` gained a heading (new `um_activity_tab_label` key) for visual parity with `ActionsSection`'s existing one. Removed the now-orphaned `user-management/actions` catalog row and sidebar sub-tab entry; updated every test/e2e spec that referenced the old two-sub-tab shape to drive the merged page instead (rail navigation to the merged sub-tab, then a button click for the inner toggle).
