## v153.4 — 2026-10-08 — Fix (daily tracking): rename tab to المتابعة اليومية and follow the month the work is dated in

**Why:** The results page's tracking tab was named «المتابعة والمواعيد»; the owner wants «المتابعة اليومية». Separately, the tab showed 0 for the calendar and the per-employee averages whenever the sample's month differed from the month the work was done in (a January sample attached and reviewed in October): every finished row is dated October, `buildTracking` only places rows dated inside the sample's month, so all of them landed in `unplaced` and the calendar/span stayed empty.

**What changed:** `tracking_tab_title` is now «المتابعة اليومية». New pure `resolveTrackingMonthFolder(monthFolder, rows, today)` in `deadlineTracking.ts`: keeps the sample's month when today falls in it or any finished row is dated inside it; otherwise follows the work — the month of the latest finished row, or today's month when nothing is finished. `ResultsTracking` runs the sample month through it, so the calendar, deadline (default last day − 3; admin overrides are keyed by the resolved month) and quota all describe the month the work is really in. Assignment/total counts are unchanged.

## v153.3 — 2026-10-08 — Change (comprehensive report): uploading both workbooks (sample + follow-up) is required

**Why:** The comprehensive report is built from two linked workbooks — the examined-sample workbook («بناءً على فترة العينة», which also carries the population) and the follow-up workbook («متابعة أعمال الفحص», which carries image availability, marking, quality, suspicion level…). The upload accepted the sample workbook alone and silently produced a report with those fields empty.

**What changed:** the upload page now requires both: `readComprehensiveWorkbooks(files, onProgress, { requireFollowUp })` throws `XQ-WB-NOFOLLOWUP` when only the sample workbook is chosen (and `XQ-WB-NOSAMPLE` when only the follow-up one is); the worker and hook always request it, and the page shows a new error message plus «both files required» hints. Both are still chosen in one multi-select; they are told apart by sheet names. The reader's default stays optional so other callers/tests are unchanged.
