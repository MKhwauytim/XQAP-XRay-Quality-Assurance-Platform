# Edit Log — 2026-09-16

## v139.0 — 2026-09-16 — Remove (ci): delete the Playwright E2E suite, its workflow, and its toolchain

**Why:** The owner reports never having seen the E2E job succeed, and the run history backs that up: it has never produced a green result. On `d7fc5808` the `Playwright (Chromium)` job ran 03:44:24Z to 04:14:38Z — 30m14s — and was cancelled, every step passing except `Run E2E suite`, which was cut off by `timeout-minutes: 30` in `.github/workflows/e2e.yml`. The two prior commits on `main` (`b74f9683`, `ea2391f2`) were also cancelled, and the job on dependabot PRs #170 and #171 hit the same wall at 30m16s and 30m15s. A suite that is killed by its own timeout on every run reports nothing about the code: it cannot fail meaningfully, so it cannot pass meaningfully either. It was costing 30 minutes of CI per push and adding a permanently red-or-cancelled check that trains everyone to ignore check status.

Raising the timeout was considered and rejected — nobody has ever seen the suite complete, so there is no evidence that a larger budget finishes rather than merely running longer before being killed, and diagnosing that is a separate piece of work from removing dead weight. The `Typecheck, lint, test, build` job (483 files / 4493 unit and component tests) is unaffected and remains the real gate.

**What changed:** Removed the E2E layer in full rather than leaving a disabled shell. Deleted the 20-file `e2e/` suite (18 specs plus three helpers, 2,373 lines), `playwright.config.ts`, the `.github/workflows/e2e.yml` workflow, and `docs/development/E2E_TESTS.md`. Removed the `e2e`, `e2e:ui`, and `e2e:report` scripts and the `@playwright/test` dev dependency from `package.json`, and regenerated `package-lock.json` (344 packages pruned; no `playwright` entry remains). Three references would have broken the build had they been left behind: `lint:ci` linted `e2e` and `playwright.config.ts` explicitly and now lints `src` alone; `tsconfig.e2e.json` was a project reference from `tsconfig.json` whose `include` would have matched no files under `tsc -b`, so both the file and the reference are gone; and the eslint override block scoping Node globals to `e2e/**/*.ts` was removed. `dist/index.html` rebuilt.

**Migration/rollback:** No data-format or release-mechanics change — nothing on disk in a user workspace is affected, and the built artifact is unchanged in behaviour. Rollback is `git revert` of this commit: the suite, config, workflow and toolchain all come back together, and `npm ci` restores `@playwright/test`. The deleted specs remain recoverable from history at `d7fc5808` should someone later fix the timeout and want them back.
