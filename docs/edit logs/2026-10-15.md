# Edit Log — 2026-10-15

## v154.1 — 2026-10-15 — Change (deck3): الملاحظات والتوصيات rebuilt in the owner's five-theme format, every figure computed from the report data

**Why:** The owner wrote the January–September 2026 الملاحظات والتوصيات by hand: five themes, each with a headline figure, evidence by risk level and by port, and numbered recommendations. The rule-drafted observations used a different structure (per-port outliers against an all-ports average), so every report had to be rewritten by hand the same way. The drafted version now follows the owner's structure and computes each number from the report model. This entry also includes the 2026-10-14 deck3 work that was still uncommitted in another worktree: the one-observation-per-page card, port averages, and the workbook import of the September `SSep`/`Sep` sheets. It also adds `نتيجة L1`/`نتيجة L2` header aliases so the October workbook copy imports.

**What changed:**
- `statements.ts`: `buildStatements` + `groupObservations` are replaced by `buildObservations(model)`. It returns five observations in a fixed order: missed suspicions, false suspicions, risk indicators (level 3), suspicion-location marking, and image quality. A theme with no data is left out.
- Bases: answers are decisions, meaning L1 and L2 are each judged against the specialist. Missed = missed ÷ (missed + correct clean). False = false ÷ (false + correct suspicion). Levels 1 and 2 use the population totals (`population.summary.byStageLevels`). Level 3's headline uses `population.summary.byStage`.
- A port is named when its share is at least 10 points worse than its port type's pooled total (at least 5 for the low-quality-only measure). It also needs at least 100 cases, and a sentence names at most 4 ports. Placeholder names («غير محدد», «منفذ بري», «منفذ بحري») are never named.
- Recommendations are the owner's text, per theme.
- `findOutliers` now compares a port with its own port type's pooled total. New helper: `typeTotal`.
- `slideKit.ts`: the dense type scale now switches on above 450 characters instead of 700, because the marking page overflowed at the larger title size.
- `supportData.ts` / the statements workbook: one row per evidence line, with numbered recommendations.
- `ownerObservations.ts` + `--owner-observations` on the export script: the owner's hand-written text, kept for the January–September report.
