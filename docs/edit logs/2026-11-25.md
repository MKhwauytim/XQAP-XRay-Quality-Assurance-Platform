## v161.2 — 2026-11-25 — Add (referrals queue): request reopen for every submitted case matching the filter

**Why:** The owner asked for the bulk form of «طلب إعادة فتح الحالة»: an employee filters the queue and asks to reopen everything that matches, next to «إسناد الكل المطابق للتصفية». Until now a reopen request could only be filed one case at a time from the inspection panel.

**What changed:** 
- `requestReopen.ts`: new `submitReopenRequests`. It calls the existing `submitReopenRequest` for each case, one after another, so each request goes through the same CAS write and the same instant-or-approval branch. A case that already has a pending request is skipped, so a second click files nothing twice. One failure does not stop the rest.
- New `ReopenFilteredButton.tsx` in the selection bar: «طلب إعادة فتح الكل المطابق للتصفية (n)». `n` counts the user's own submitted cases among the filtered rows (the same rule as the single request: own case, submitted, not replaced). The dialog requires a reason, as the single request does.
- `ReassignSelectionBar` takes `extraActions` and `canReassign`. The bar now also shows for a user who may submit answers but may not file reassignments; for that user it carries only the reopen button.
- A case that was never submitted cannot be reopened, so on the «لم تُفحص» chip the count covers only on-hold cases that were submitted.
- Labels: `ew_reopen_filtered_*`.
