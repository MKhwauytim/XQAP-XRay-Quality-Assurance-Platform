# Edit Log — 2026-11-09

## v160.7 — 2026-11-09 — Change (port report): v160.7 one report per year, transit on or off, duplicates are the same image id in the same month

**Why:** The owner switched to a new source workbook («2025-2026 Raw.xlsx», 648 MB: eight quarter sheets plus «نتائج الدراسة») and asked for a separate report for each year, with 2026 produced twice: once with transit declarations and once without. They also asked that no data be dropped, except true duplicates, which they defined as the same image id in the same month after all sheets are appended. A scan of the new file found:
- 2026-Q1 carries all of December 2025: 218k rows repeat 2025-Q4, plus 71k transit and 14k new rows.
- 2026-Q3 repeats 104k ids inside the sheet.
- 2026-Q1 and 2026-Q2 hold 68k and 269k empty rows.
- 2026 result text reads «نتيجة اشتباه -مبدئي» and «إشتباة», which the exact «اشتباه» test missed.

The workload year was hard-coded to 2025, so a 2026-only report had no load year and every port fell out of the tiers. The monthly timeline also hid the errors of any month that had no population rows.

**What changed:**
- `workloadAggregate.ts`:
  - A duplicate is now (image id, month) across all sheets, so each row counts in the month of its own date, whichever sheet holds it.
  - Every month is counted twice in the same pass, with and without «البيان» = ترانزيت (`monthsNoTransit`), and the transit image ids are kept (`transitIds`).
  - Suspicion matches every spelling (`/[اإ]شتبا[هة]/`).
- `portReportSource.ts` reads the study row's image id and drops a repeat of the same id in the same entry month.
- `portReportBuild.ts`:
  - New `excludeTransit` option: uses the no-transit months and drops transit study rows.
  - The load year is LOAD_YEAR, or the report's latest year when LOAD_YEAR is excluded. `buildPortWorkloads` takes it and stores it on each port.
  - `excludeYears` falls back to the entry month when the capture year is missing.
- `portReportHtml.ts`: the timeline shows every month in the period. A month with no population rows leaves a gap in the received line, and a note lists those months.
- Port tool:
  - New «استبعاد الترانزيت» checkbox, shown only when the workbook has transit rows.
  - The file name says «بدون ترانزيت» when the box is ticked.
- Export script and `poc/port-pptx/buildModel.mjs`: new `--exclude-transit` flag. The export script also prints the transit count for each sheet.
