## v131.9 — 2026-09-03 — Fix (distribution): keep per-employee sample totals equal when port restrictions are active

**Why:** With any employee port-restricted, `calculateBulkAssignment` partitioned a stage's rows by port and re-apportioned each port independently at 100% among only that port's eligible employees, using each employee's raw configured percentage as the weight. A restricted employee's excluded share on the ports they couldn't reach was never made up elsewhere, and employees who happened to share fewer ports with others were over-weighted on those ports — so with four employees configured at an equal 25% each, real totals drifted to reports like 1,800 / 2,000 / 2,500 / 1,400 instead of an equal split.

**What changed:** Before partitioning a restricted stage by port, `calculateBulkAssignment` now computes each employee's overall target for the WHOLE stage once (Hamilton apportionment of the stage's total row count by their configured percentage/exact value), then processes ports most-constrained-first (fewest eligible employees first) and apportions each port using each eligible employee's *remaining* stage-wide need as an exact-count weight, decrementing that shared pool as rows are actually assigned. This keeps every employee's final total anchored to their configured percentage regardless of how the stage happens to split across ports, while an employee with fewer allowed ports still draws a bigger share of the ports they can reach to make up the difference.

```ts
const remainingNeed = new Map(
  hamiltonApportionment(
    stageAllocs.map((a) => ({
      key: a.username,
      size: Math.max(0, a.method === "percentage" ? Math.round(a.value * 100) : a.value),
    })),
    stageRows.length
  ).map((q) => [q.key, q.allocated])
);

const portGroups = [...rowsByPort.entries()]
  .map(([portKey, portRows]) => ({
    portKey,
    portRows,
    eligibleAllocs: stageAllocs.filter((a) => isPortEligible(a.username, portKey, portRestrictions)),
  }))
  .sort((a, b) =>
    a.eligibleAllocs.length !== b.eligibleAllocs.length
      ? a.eligibleAllocs.length - b.eligibleAllocs.length
      : a.portKey < b.portKey ? -1 : a.portKey > b.portKey ? 1 : 0
  );

for (const { portKey, portRows, eligibleAllocs } of portGroups) {
  if (eligibleAllocs.length === 0) {
    errors.push(/* ... */);
    continue;
  }

  const portAllocs = eligibleAllocs.map((a) => ({
    ...a,
    method: "exact" as const,
    value: remainingNeed.get(a.username) ?? 0, // shared remaining need, not raw percentage
  }));

  const group = assignWithinGroup({ rows: portRows, stageAllocs: portAllocs, /* ... */ });
  events.push(...group.events);
  errors.push(...group.errors);

  for (const event of group.events) {
    remainingNeed.set(event.assignedTo, Math.max(0, (remainingNeed.get(event.assignedTo) ?? 0) - 1));
  }
}
```
