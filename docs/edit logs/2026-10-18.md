## v154.1 — 2026-10-18 — Fix (answers): «قيد الحفظ» badge for outbox answers not yet on the share; pending overlay + banner for every role

**Why:** An employee pressed «تقديم», saw «تم تقديمها» and «مكتملة», but the supervisor never saw the answers. In outbox mode a submit is durable only in this browser until the background flush lands it on the share, yet the row badge already read «مكتملة», so nobody could tell a local-only answer from a saved one. Oversight users (`view-all-entries`) also skipped the pending overlay and banner, so their own queued answers disappeared on reload.

**What changed:** New `status_saving` «قيد الحفظ» badge (with an explanatory tooltip) shown instead of «مكتملة» while a submitted answer is still queued locally; set on an outbox submit, recomputed from the IndexedDB pending records on every load, so it flips to «مكتملة» on the reload the flush broadcasts. Pending overlay and the unsent-answers banner now apply to every role.
