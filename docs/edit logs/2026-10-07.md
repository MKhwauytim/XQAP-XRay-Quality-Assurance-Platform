## v151.12 — 2026-10-07 — Change (reports): pause report hub as تحت الصيانة, drop old executive report, make comprehensive deck3 editable with saved text templates

**Why:** The text-edit feature had been built on the wrong report. The report the owner means is the deck3 executive deck (the file `executive2.html`), which is produced by the «تقرير تنفيذي شامل» sub-tab; the older executive card, its deck-edition toggle and the document edition were superseded and confusing.

**What changed:** (1) Reports hub: the old executive card, its «التصميم الجديد» toggle, the quick-actions row and the admin design-customizer are removed; the three remaining cards (population, management, Power BI) and the KPI dashboard's export buttons are greyed out with «تحت الصيانة» (`REPORTS_UNDER_MAINTENANCE` in TabView.tsx; the generators are kept so lifting the flag restores them). The old executive «document» edition is no longer reachable from any UI. (2) Comprehensive executive tab: deck3 is the only deck (v2 and the edition preference are no longer read). (3) deck3 viewer is editable: «تعديل النص» makes every leaf text element contenteditable; «حفظ كقالب» posts the changed leaves to the app window, which stores them in `6-templates/executive-deck-text-templates.json` (CAS-protected, max 50, same-name replaces); the tab offers a template picker that re-applies a template at export. Entries are keyed by section|slide|leaf position and carry the original text; on apply an entry is skipped unless the original still matches, so a template can never overwrite a different figure. Edit chrome is opt-in (`textTemplate !== undefined`), so the population deck output is byte-identical (its goldens are unchanged). `deckEditionPreference.ts` is kept only because `templateFileRecovery.ts` still lists its file. The deck2/deck/document builders are left in place (deck3 imports deck2 helpers); only their UI entry points were removed.
