 * Tracks every tab/sub-tab ID that has ever been the active one, so a caller
 * can keep previously-visited content mounted (hidden, not unmounted)
 * instead of reloading it on every switch back.

 * Unlike touchTabMountLru (which bounds a large, dynamic top-level tab set

export function touchVisitedTabs<T>(current: ReadonlySet<T>, activeId: T): Set<T> {

## v59.137 — 2026-08-03 — Add (distribution): incremental append-only cache for immutable event reads

**What changed:** `distribution.events/` is genuinely append-only (an event, once written, is never modified — enforced by `writeImmutableDistributionEvent`'s own collision rejection), but every read of it — including `loadOrDeriveDistributionCurrent`'s hot path, called on effectively every distribution-tab render/refresh — re-read every event file from scratch every time, with no cross-call caching.   const d = dir as DirectoryHandleLike & {
    values?: () => AsyncIterable<DirectoryEntryLike>;
    entries?: () => AsyncIterable<[string, DirectoryEntryLike]>;
    [Symbol.asyncIterator]?: () => AsyncIterator<DirectoryEntryLike>;
