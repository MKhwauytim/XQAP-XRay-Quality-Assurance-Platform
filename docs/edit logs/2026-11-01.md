# Edit Log — 2026-11-01

## v157.0 — 2026-11-01 — Add (months): merge a month or an ad-hoc sample into another month

**Why:** The owner had cases from many unchecked months (October, February…) uploaded into a single month (January), partly as an ad-hoc sample and partly into other months. Following up meant juggling several months and the ad-hoc list. They asked for one place to fold a month — or an ad-hoc sample — into a chosen month with its sample, assignments and answers intact, the ad-hoc count going to zero, and the emptied month archived rather than hard-deleted.

**What changed:**
- New `src/data/monthTransfer/monthTransfer.ts`: `planMonthTransfer` (read-only preview: rows to move, duplicates, events, answers, population rows, pending requests left behind) and `executeMonthTransfer`. Order: sample rows → distribution events (by eventId, only for moved rows) → answers via `upsertItemAnswer` (final state) → population rows → archive copy → delete the source. A row already in the target is a duplicate and is skipped (kept in the archive) unless one of the source's own events for it is already in the target, which marks an earlier partial run that is then resumed; so a re-run after a failure is safe and the source is deleted only after every step succeeded. Closed months are refused, as is a target with no drawn sample. An `adhoc-{id}` source has the same layout, so the same engine moves an ad-hoc sample; its import record is archived and removed from the index.
- New `archiveMonthFolders.ts`: byte-verified copy of `1-population/{m}` and `2-samples/{m}` into `5-system/archived-months/{m}--{ISO stamp}/` before removal.
- `sampleStorage.ts`: new bulk `appendSampleRows` (CAS, skips present ids, keeps moved retired rows retired, recounts totals/allocations).
- `populationStorage.ts`: new `appendPopulationFinalRows` (manifest lock, archives the superseded file first, dedupes by `xrayImageId`, recounts totals).
- Settings: new admin-only «دمج شهر أو عينة استثنائية في شهر» section (`MergeMonthSection.tsx`) next to «حذف شهر» — pick source (months + ad-hoc imports) and target, preview, confirm. New audit action `month-merged`; labels added to `labelsStore.ts`; simulator seed and its pinned counts updated for the new action type.
- Extra samples from an Excel file go through the existing «استيراد استثنائي» workbench (parsing, column mapping, distribution, historical answers) and are then merged with this tool — no second parser.

Not moved: pending referral/replacement/reopen requests (counted in the preview, kept in the archive). Answers move as their final saved state, not their full event history (the history stays in the archive). Moved assignments keep the daily quota frozen in their original month.
