## v121.0 — 2026-08-25 — Refactor (ew/xray-referrals): replace the corner-grip resize with a permission-gated shared divider drag

**Why:** PR #95's admin-only corner-grip resize (merged this session) turned out genuinely broken in real use — the owner reported "i click on it i try to move it right and left nothing happens", traced to the grip rendering below the viewport fold (`bottom: 1015.59px` inside a 900px-tall scrolled container), so a synthetic drag hit nothing (`document.elementFromPoint` returned `null` at that position). Rather than patch the grip's position math, the owner gave an explicit redesign brief with a screenshot: drag the *existing middle divider line* (`QueueSplitResizer`, an independently-shipped, per-browser-only feature this session's PR had left running alongside the broken grip), gate dragging behind a permission that defaults **on for every role** rather than admin-only, keep "an admin's drag reflects to everyone" as a *separate*, privilege-gated behavior layered on top of that same divider, reclaim the large unused margins `.page-shell`'s shared 1600px cap left on wide monitors, and fix the inspection panel finishing shorter than the table+pagination (forcing extra scroll) while also being too wide by default (crowding the panel's own phase stepper and hiding table columns). The grip mechanism (`useQueuePanelResize`, `XrResizeGrip`, `ResizeModeToggle`) is retired outright rather than fixed in place, since the redesign replaces its entire interaction model.

**What changed:**
1. New feature permission `resize-referral-layout` (`userManagement.ts`, `employee-workspace` feature map): defaults **on** for guest/employee/supervisor/manager (admin is always implicitly on). Gates only whether a role sees/can operate the divider handle at all — not the ratio it resolves to, which always applies regardless.
2. `QueueSplitResizer` gains `enabled`/`sharedRatio`/`onCommit` props: `enabled` toggles the interactive affordance (role/aria/tabIndex/handlers) without ever unmounting the handle — unmounting would stop `gridOf()` (`closest(".ew-xr-grid")`) from finding the grid at all, silently breaking the ratio-resolution for a role without the permission (caught by a new test before it shipped). `sharedRatio` is a privileged user's ratio loaded from the workspace-shared admin browse preset; `resolveQueueSplit()` (new in `queueSplitStore.ts`) prefers this browser's own stored drag over it, and the hardcoded default over both — the same personal-over-admin precedence this page already uses for column layout. `onCommit` fires the persisted ratio back to the caller on release/keyboard-nudge/reset so a privileged drag can additionally push to the shared preset.
3. `XrayReferrals.tsx`: wires `canResizeLayout = can("resize-referral-layout")` and a `sharedSplitRatio` state loaded alongside the existing admin/user column presets; `handleSplitCommit` pushes `{ ratio }` into the same `saveAdminBrowseDatasetPreset` call the column config already writes through, gated on `canConfigureColumns` (unchanged permission — only a user who can already push shared column layout can push a shared split). The grip (`XrResizeGrip`, `ResizeModeToggle`, `useQueuePanelResize`, `XR_SPLIT_*` constants) is deleted from `subComponents.tsx`.
4. `browsePresetStorage.ts`: `BrowseDatasetPreset.layout` simplified from the grip-era `{queueFr, panelFr, heightPx}` shape to `{ ratio }`, mirroring `queueSplitStore`'s own value directly — no unit conversion needed at the read/write boundary.
5. `XrayReferrals.css`: `.page-shell.ew-xr-page-shell { max-width: 2400px; }` raises this one page's width cap above the shared 1600px primitive (untouched for every other page). The panel/table height-mismatch bug — pre-existing before either the grip or the divider work, inherent to the original grid rewrite — is fixed by changing `.ew-xr-panel-col`'s `grid-row` from `2 / 4` to `2` (and `3 / 5` to `3` for the `--with-bar` variant): the panel column was spanning both the table row AND the pagination row while its own max-height formula never accounted for the pagination row's height, so it always rendered ~40–50px shorter than table+pagination combined, forcing extra scrolling to reach the table's own controls. The grip's entire CSS block (~55 lines) is deleted; `grid-template-columns` drops the grip's `--ew-xr-queue-fr`/`--ew-xr-panel-fr` fallback chain back down to a single `var(--ew-xr-queue-basis, …)`.
6. `labelsStore.ts`: removes the now-unused grip labels (`ew_xr_resize_toggle_aria`/`_label`/`_title`, `ew_xr_resize_grip_title`); the divider's own existing labels are unchanged.
7. Tests: `QueueSplitResizer.test.tsx` gains coverage for the disabled-but-still-applies-ratio case (the bug caught during development), personal-over-shared precedence, the shared ratio resolving asynchronously after mount, and `onCommit` firing on release/keyboard/reset. `queueSplitStore.test.ts` gains coverage for `hasStoredQueueSplit`/`resolveQueueSplit`.

**Migration/rollback:** No on-disk schema bump — `layout.ratio` is a new optional shape under the same `BrowseDatasetPreset.layout` key the grip's `{queueFr, panelFr, heightPx}` occupied; a preset file written by the retired grip code is simply not read by the new `?.layout?.ratio` accessor (falls through to the hardcoded default) rather than throwing. Rollback is reverting this commit; no data migration either direction.

// QueueSplitResizer.tsx — always mounted; enabled only gates the interactive affordance
export default function QueueSplitResizer({ enabled, sharedRatio, onCommit }: { ... }) {
  const [ratio, setRatio] = useState(() => resolveQueueSplit(sharedRatio));
  useLayoutEffect(() => {
    const grid = gridOf();
    const next = resolveQueueSplit(sharedRatio);
    if (grid) apply(grid, next);
    setRatio(next);
  }, [gridOf, sharedRatio]);
  // ...
  return <div ref={handleRef} className={`ew-xr-split-handle${enabled ? "" : " ew-xr-split-handle--disabled"}`}
    role={enabled ? "separator" : undefined} onPointerDown={enabled ? onPointerDown : undefined} ... />;
}
// XrayReferrals.tsx — one permission, personal-over-shared precedence, no separate grip
const canResizeLayout = can("resize-referral-layout");
const handleSplitCommit = useCallback((ratio: number) => {
  if (!canConfigureColumns) return;
  void saveAdminBrowseDatasetPreset(directoryHandle, REFERRALS_PRESET_KEY, { ...effectiveColConfig, layout: { ratio } });
}, [canConfigureColumns, effectiveColConfig, baseColumns, directoryHandle]);
// ...
<QueueSplitResizer enabled={canResizeLayout} sharedRatio={sharedSplitRatio} onCommit={handleSplitCommit} />
