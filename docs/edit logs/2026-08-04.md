## v59.170 — 2026-08-04 — Fix (auth): pause the periodic permission/data-refresh tick while the tab is hidden

**What changed:** The 5-minute permission/data-refresh auto-refresh interval in `AuthGate.tsx` did real work (a disk read via `refreshPermissions()`, plus a fan-out `broadcastDataRefresh("periodic")` signal to every mounted view) on every tick regardless of whether the tab was even visible. ## v59.168 — 2026-08-04 — Fix (workspace): scope the append-only cache's data-refresh reset to the manual admin refresh only

**What changed:** A single global `xray-data-refresh` signal was broadcast from both the admin toolbar's manual refresh button and the 5-minute periodic auto-refresh timer, with no way for subscribers to distinguish which triggered it. `directoryScan.ts`'s append-only read cache subscribed to this signal and wholesale-reset on every broadcast — including the periodic one, defeating its own correct per-file name-diff invalidation for no benefit every 5 minutes. Grepped every other `subscribeToDataRefresh` subscriber in the codebase and confirmed each remains source-agnostic. `tsc -b` clean (this changes an exported function's public signature). Independent task review re-ran all of the above and confirmed both of the implementer's noted deviations (a `jsdom` test-environment pragma; a corrected module-init comment) were genuine necessities, not scope creep.

**Before:**
