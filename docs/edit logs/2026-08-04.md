## v59.179 — 2026-08-04 — Add (storage): mapWithConcurrency shared bounded-concurrency primitive

**What changed:** New standalone primitive `mapWithConcurrency<T, R>(items, limit, fn)` in `src/data/storage/concurrency.ts` — modeled on the worker-pool shape already proven in this codebase (`directoryScan.ts`'s `readNamedJsonFiles`): index-addressed results (never `.push()`-on-completion, preserves determinism), fail-fast-then-drain (stop starting new work on first error, await everything already in flight, then throw). **Fixed during implementation:** the initially-drafted `if (firstError === undefined) throw firstError` error check would have silently swallowed a rejection whose value is literally `undefined` (`throw undefined`/`reject(undefined)`). Replaced with an explicit `hasError` boolean decoupled from the error's actual value.

**Verification:** 4 new tests (order-survives-out-of-order-completion, concurrency-limit enforcement, fail-fast-then-drain, edge-case clamping). Independent task review hand-traced the `reject(undefined)` fix against the actual code and confirmed it closes the gap; noted the fail-fast-then-drain test's own assertions are weaker than intended (partially tautological given the fixture's push order) but independently verified the underlying code is correct by direct trace regardless.

**File:** `src/data/storage/concurrency.ts`, `src/data/storage/concurrency.test.ts`

**After:** (corrected 2026-08-04 — the block previously here used a single `hasError` flag as both the error record and the worker-loop stop signal; the shipped code actually uses two separate flags, `hasError` and `stopped`, so a worker's in-flight iteration checks `stopped` rather than `hasError` — behaviorally equivalent, but this is now the exact code that landed)
```ts
export async function mapWithConcurrency<T, R>(
  items: readonly T[],
  limit: number,
  fn: (item: T, index: number) => Promise<R>
): Promise<R[]> {
  const results: R[] = new Array(items.length);
  const workerCount = Math.max(1, Math.min(limit, items.length || 1));
  let nextIndex = 0;
  let firstError: unknown;
  let hasError = false;
  let stopped = false;

  async function worker(): Promise<void> {
    while (true) {
      if (stopped) return;
      const index = nextIndex++;
      if (index >= items.length) return;
      try {
        results[index] = await fn(items[index] as T, index);
      } catch (error) {
        if (!hasError) {
          hasError = true;
          firstError = error;
        }
        stopped = true;
```
