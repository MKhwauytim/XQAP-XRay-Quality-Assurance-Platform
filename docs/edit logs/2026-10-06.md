# Edit Log — 2026-10-06

## v151.1 — 2026-10-06 — Fix (reports): comprehensive report opens the executive deck, not the detailed document

**Why:** The «تقرير تنفيذي شامل» page's main button opened the old detailed document (`openExecutiveReport`), not the executive deck (deck v2, the live default the Reports tab opens). v151.0 left the deck out because its slides still rendered population, sample-coverage and per-month source figures that do not exist for a completed-samples-only report.

**What changed:** Deck v2 now honours `model.scope === "completed-only"`: section 1 (مجتمع الفحص) and section 4 (التغطية والمساءلة) are omitted with their TOC rows, and page ranges are computed over what remains; the cover shows the completed-sample count and the scope note instead of population/sample/coverage; the closing slide replaces the per-month source cards with the completed-samples card. On that scope every cover/closing style slot renders the adjusted default body. The scope note's style is inline so the full-scope deck output (golden snapshot, theme CSS) stays byte-identical. The comprehensive page's button is now «التقرير التنفيذي» (`ce_generate_deck`, replacing `ce_generate_doc`) and calls `openExecutiveDeckV2` with the workspace's saved deck style choices; the XLSX button is unchanged.

**Known limits:** section numbering is kept (the deck goes المعجم → القسم الثاني → القسم الثالث) so separators, nav labels and the printed side rail agree; the side rail still lists a «مجتمع الفحص» tab. Deck v3 does not honour the scope yet and is not offered on this page, even when the workspace's edition preference is v3.
