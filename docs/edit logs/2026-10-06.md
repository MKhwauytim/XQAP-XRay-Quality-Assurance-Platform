## v151.1 — 2026-10-06 — Fix (workbookImport): read the examined-sample layout (SJAN…SDEC) of the comprehensive report workbook

**Why:** The «بناءً على فترة العينة» workbook names its sample sheets `SJAN`…`SAUG` (not `Q*_Sample`), uses different headers (`رقم صورة الاشعة`, `شهر الفحص`, `نتيجة المستوى الأول للاشعة`/`الاول`), has no «الاكتمال» column and stores the month as a bare number (1–8) with no year, so the importer failed with `XQ-WB-NOSAMPLE` and read 0 rows.

**What changed:** `SAMPLE_SHEET` also accepts `S<MON>`; header aliases (`HEADER_ALIASES`/`canonicalHeader`) map the examined layout onto the canonical names; a sheet with `شهر الفحص` and no «الاكتمال» is read as «examined» (every row is a completed sample); a bare month 1–12 takes its year from `تاريخ رصد الخبير` (rows without one count as `skippedNoMonth`); `سليمه` is read as `سليمة`. Q*_Sample behaviour is unchanged. Real file check (not committed): 56,468 rows → 56,373 mapped (37 no derivable month, 58 junk result values).
